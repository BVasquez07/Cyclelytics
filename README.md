# Allure Test Reports

This branch (`allure-reports`) is **automatically maintained** and contains test reports generated by CI/CD.

**Do not commit directly to this branch.**

- Reports are auto-generated from test runs on the `main` branch
- Hosted via GitHub Pages at: https://BVasquez07.github.io/Cyclelytics/
- Latest report reflects the most recent test execution

## Technologies

- **GitHub Actions** - CI/CD Automation
- **pytest** - Test execution framework
- **pytest-asyncio** - Async test support
- **allure-pytest** - Test reporting plugin
- **Allure CommandLine** - HTML report generation
- **uv** - Python package manager & dependency management
- **GitHub Pages** - Report hosting

Generated automatically on every push/merge to `main`.
